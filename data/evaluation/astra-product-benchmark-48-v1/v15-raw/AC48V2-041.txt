This memo asks for permission to finish checking the library's donated puzzles and to run a small test of lending them.

Where things stand

The cupboard holds forty puzzles, but only twenty-six have been checked for missing pieces. We should not call all forty ready to borrow. The fourteen unchecked boxes are on the lower shelf, each with a yellow paper band around it.

Of the twenty-six checked, eighteen were complete and eight were missing between one and five pieces. The volunteer group suggests lending those eight with a clear label, so borrowers can decide whether they still want them. This is only a suggestion, and the library manager has not approved it. A missing piece doesn't always make a puzzle unusable, and we shouldn't make that decision for the borrower.

Finding puzzles

Some boxes have tiny printed titles, and three have no picture of the finished puzzle. Larger shelf labels could help visitors find a puzzle, and a simple photograph could show them the image. Neither improvement has been costed. We have a camera, but nobody has agreed to take the photographs or maintain the labels.

Lending

Staff propose using the existing board game loan system. Puzzles would have a fourteen-day loan period, with one renewal if there is no reservation. The system can record a note about missing pieces. It can't currently record a photograph, so photographs would have to stay with the physical boxes.

The request

We ask for permission to finish checking the remaining fourteen puzzles and to test the loan system with two complete puzzles. The test would show staff how returns work before we open the whole cupboard. It would not settle the proposal to lend incomplete puzzles.

Please send comments to the circulation supervisor by Wednesday so the manager can review the request at Friday's meeting.
