# Astra control fresh 48 v2

Experiment `astra-control-fresh-48-v2` prospectively asks whether frozen Candidate C improves on frozen V15 without sacrificing meaning safety, and compares C with Astra as a direct editor. This is an internal descriptive product pilot, not a universal safety or statistical superiority claim. Protocol and contract JSON are authoritative; no cases, prelabels or outputs exist at registration.

V1 remains **BLOCKED — HUMAN PARTICIPANT CONTRACT UNSATISFIABLE IN CURRENT WORKFLOW**. It was never executed and is not a scientific failure. V2 is a separate experiment; it changes procedural participation, not the frozen candidate architecture, safety classes, lexical thresholds or advancement thresholds.

Two independent AI creator sessions produce 24 synthetic cases each under fixed strata, length and orthogonal quotas. One independent AI semantic reviewer screens all cases against the bounded inherited inventory (695 artifact versions; 50,915 reference occurrences), supplementing the exact frozen deterministic screen. Custodian material selection strips prior outcomes; creators see no excluded examples. Insufficient reference access blocks corpus freeze. Replacements retain creator role, ID and coverage slot, preserve rejected hashes and reasons, and repeat unchanged checks before lock. No post-lock case edit or replacement is allowed.

Two fresh output-blind AI sessions independently prelabel every locked case: 96 original records. Exact field differences are mechanically recorded and preserved without forced consensus. Prelabels never enter editor or initial blind judge packets. Subsequent authorization disagreements cannot be erased with a convenient imagined output.

Independence means separate invocations, no inherited conversation, role memory or unauthorized input access, with recorded provenance. It does not claim different pretraining or statistically independent errors. The non-Astra `gpt-6.1-sol`, effort `high`, is frozen for future blind judging; each required stage has two independent sessions, with one third blind adjudicator only under the frozen disagreement rule. Text-only packets use opaque IDs and independently randomized order/orientation; traces and identities stay private until ratings lock. SOURCE equality and identical outputs permit partial recognition, which is recorded rather than hidden. Optional human review after unblinding is not a validity prerequisite.

The four arms are SOURCE, V15, C_DOWNSTREAM and ASTRA_DIRECT. SOURCE preserves input bytes. Inputs changed by V15/C schema parsing or trimming are rejected, never normalized. C receives the exact saved V15 RAW bytes after V15 RAW/FINAL freeze, with no separate editor draw. Astra uses `gpt-6-astra`, reasoning effort `high`, reasoning mode omitted, no tools/browsing/cross-case memory/automatic retry, and one fresh invocation per case. Access, spend, durable storage and runtime checks are OUTPUT EXECUTION prerequisites, not corpus prerequisites. Record returned model metadata; an unavailable immutable served revision is not a gate.
